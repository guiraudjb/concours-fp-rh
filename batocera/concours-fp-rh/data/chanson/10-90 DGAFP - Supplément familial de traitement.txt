TITRE : Le rythme du SFT Riddim

[Intro]
Écoute bien la règle du supplément familial,
Pour les agents publics, c'est un droit essentiel.

[Couplet 1]
Magistrats, militaires ou fonctionnaires de l'État,
Le SFT est pour vous, un complément de combat.
Mais attention aux contractuels ou aux taux horaires,
Ils sont exclus de ce calcul de salaire.
L'enfant doit être à charge, matériel et moral,
Jusqu'à vingt ans sauf s'il gagne un salaire anormal.
Plus de cinquante-cinq pour cent du SMIC brut,
Et le droit s'arrête, le calcul devient nul.

[Refrain]
SFT, supplément familial de traitement,
Pour les enfants à charge, c'est le règlement.
Allocataire ou attributaire, ne confonds pas les deux,
C'est la règle du droit pour rendre les agents heureux.

[Couplet 2]
La part fixe augmente avec le nombre d'enfants,
Deux virgule vingt-neuf euros pour un seul enfant.
Dix virgule soixante-sept pour deux, quinze virgule vingt-quatre pour trois,
Puis quatre virgule cinquante-sept pour les suivants, c'est la loi.
La part variable dépend de l'indice de traitement,
Trois pour cent pour deux enfants, huit pour cent pour trois, vraiment.
Six pour cent pour chaque enfant au-delà du troisième,
C'est le calcul précis pour monter dans le système.

[Refrain]
SFT, supplément familial de traitement,
Pour les enfants à charge, c'est le règlement.
Allocataire ou attributaire, ne confonds pas les deux,
C'est la règle du droit pour rendre les agents heureux.

[Pont]
En garde alternée, l'enfant compte pour zéro virgule cinq,
Le partage est par moitié, pour que personne ne s'en plainte.
Pas de cumul si l'employeur public donne le même droit,
Mais avec le privé, le cumul est une joie.

[Refrain final]
SFT, supplément familial de traitement,
Pour les enfants à charge, c'est le règlement.
Allocataire ou attributaire, ne confonds pas les deux,
C'est la règle du droit pour rendre les agents heureux.

[Outro]
CSG et CRDS entrent dans le calcul,
Le service payeur gère tout, sans aucun mal.
