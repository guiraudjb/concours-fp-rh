TITRE : Le Rythme du Reclassement Riddim

[Intro]
Écoute la vibration du droit et du maintien,
Pour les agents de l'État, on trace le chemin.

[Couplet 1]
Le CGFP guide nos pas dans la fonction,
Le médecin du travail propose l'adaptation.
Le médecin agréé complète son action,
Pour l'aptitude et la bonne direction.
Si l'aménagement ne suffit plus au quotidien,
L'affectation sur un autre emploi fait le bien.
Mais si le conseil médical rend un avis d'inaptitude,
La procédure de reclassement devient la seule étude.

[Refrain]
PPR ou reclassement, c'est le droit de l'agent,
Pour rester dans l'emploi malgré les tourments.
Le traitement est maintenu, garde la sérénité,
Dans la fonction publique, on cherche la dignité.

[Couplet 2]
La PPR est de droit pour le titulaire,
Douze mois maximum pour changer de carrière.
Le projet doit être notifié sous deux mois,
L'administration doit agir avec foi.
Le FIPHFP peut financer la formation,
Dix mille euros de plafond pour la préparation.
Le fonctionnaire garde son traitement intégral,
Sauf la NBI, c'est le principe fondamental.

[Refrain]
PPR ou reclassement, c'est le droit de l'agent,
Pour rester dans l'emploi malgré les tourments.
Le traitement est maintenu, garde la sérénité,
Dans la fonction publique, on cherche la dignité.

[Pont]
Le stagiaire n'a pas de droit au reclassement,
Sauf s'il est blessé en mission de l'État, vraiment.
L'agent contractuel suit un décret spécifique,
Pour son maintien dans l'emploi, c'est un objectif.

[Refrain final]
PPR ou reclassement, c'est le droit de l'agent,
Pour rester dans l'emploi malgré les tourments.
Le traitement est maintenu, garde la sérénité,
Dans la fonction publique, on cherche la dignité.

[Outro]
Respecte le décret du trente novembre mille neuf cent quatre-vingt-quatre,
Pour que le parcours de l'agent soit toujours exemplaire.
