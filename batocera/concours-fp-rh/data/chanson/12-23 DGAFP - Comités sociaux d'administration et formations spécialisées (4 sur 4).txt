TITRE : Dialogue Social Riddim

[Intro]
Écoute le rythme du CSA et de la FS,
Le dialogue social pour que tout soit vrai.

[Couplet 1]
Quinze jours avant pour la convocation,
Par voie électronique pour la communication.
Huit jours en cas d'urgence pour les dossiers,
Moins de vingt-quatre heures si le danger est réel.
Le quorum est la moitié des voix délibératives,
Pour que la réunion soit tout à fait effective.
Les suppléants reçoivent les documents par mail,
Mais seuls les titulaires siègent pour le travail.

[Refrain]
CSA, FS, le dialogue est en marche,
Pour les agents, c'est la même arche.
On vote à main levée, on suit les règles,
Pour un travail sain, sans aucun obstacle.

[Couplet 2]
Deux jours ouvrables pour l'amendement,
Présenté au président pour un bon changement.
Si le vote est unanime défavorable,
Réexamen entre huit et trente jours, c'est le cycle.
L'expert certifié intervient un mois maximum,
Pour éclairer la FS avec un vrai maximum.
Le procès-verbal est transmis sous un mois,
Pour que chaque débat garde son éclat et sa foi.

[Refrain]
CSA, FS, le dialogue est en marche,
Pour les agents, c'est la même arche.
On vote à main levée, on suit les règles,
Pour un travail sain, sans aucun obstacle.

[Pont]
Le président informe des suites sous deux mois,
Par écrit individuel pour que chacun sache quoi.
La publicité pour les agents est une obligation,
Pas seulement pour les syndicats, c'est la condition.

[Refrain final]
CSA, FS, le dialogue est en marche,
Pour les agents, c'est la même arche.
On vote à main levée, on suit les règles,
Pour un travail sain, sans aucun obstacle.

[Outro]
Respecte le décret, respecte le guide,
Le dialogue social est notre seul guide.
